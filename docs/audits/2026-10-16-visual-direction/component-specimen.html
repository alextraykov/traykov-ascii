Component specimen

Every recurring part of the site, rebuilt from the same few marks: dithered cells, hairlines, Departure Mono, plain words, and one shared timing. Everything here is clickable.

One system

six primitives · one state ladder · every component draws from both

Components don't get their own visual ideas. Each one composes the same six primitives and moves through the same state ladder. That is how a site with many component types still reads as one object.

State ladder

The same eight states, drawn the same way, on every interactive component.

LabelRestSolid hairline, ink text.
LabelHoverA solid marker arrives at the edge and the label steps aside. Nothing behind the text.
LabelFocus2px ink outline. Never removed.
LabelPressed · selectedDiagonal dither fill to solid.
SendingWorkingA loader in place, plain word.
SentDoneThe marker stays, a green cell check, the new word. Then back to rest.
LabelDisabledA dotted outline, muted text, and the reason in words.
Try againErrorPlain sentence, two short flashes, then still.

Navigation

current page as a cell rule · tools as cells · a menu that switches on

The current page is a solid cell rule under its link. Hovering another link fills its rule in reading order, and choosing it hands the rule over. Your logo mark leads; Labs joins the top level. The only tool left in the bar is a quiet, icon-only theme control whose interior dithers when you flip it. The motion setting moves to the footer.

Buttons and links

three button roles · one link style · every state on the ladder

Three roles, and no more. On hover, every button gets a solid marker at its left edge and the label steps aside. Primary fills solid through the dither, walks through Sending, and ends on Sent with a green cell check. Secondary gets the same hover marker and presses to solid. Quiet is a text action whose dither rule turns solid. Inline links use the same rule.

    Notes
      Labs

        SVG → 3D ASCII, redesigned

        same render engine · new UI around it

        The render engine stays exactly as it is: the Three.js extrusion and ASCII sampling in studio.js are untouched. Only the UI around it changes. These are screens of the working preview, rendered by the real engine; on the dev server it lives at /svg-ascii-studio/redesign/.

        One thing at a time

        A step strip (solid done, dither here, empty next) replaces three equal panels. Adding a mark, choosing a look and exporting each get their own band.

        Fewer, clearer controls

        Six sliders on cell tracks, not 30 at once. The rest sits under "More controls", grouped as Characters, Shape, Angle and camera, Colour and material, Light, and Pointer.

        Plain names

        Threshold becomes Cut-off, Ramp becomes Characters, FOV becomes Lens, and Rotate X/Y/Z become Tilt, Turn and Lean. "Detail", which made characters coarser as it went up, becomes Character size.

        Export first, formats later

        Download PNG and Copy ASCII lead. Text, SVG, settings, Three.js code and sharing fold into "More formats". The settings JSON and code panels no longer sit open.

        Diagnostics out of the way

        Security, geometry and load diagnostics move into "About this file", next to the original SVG. Status reads in one sentence under the stage.

        One drop target per state

        Empty: the whole stage. Loaded: "Replace mark", which also accepts a drop, and "Start over". The old duplicate drop areas and "Hide panel" buttons are gone.
