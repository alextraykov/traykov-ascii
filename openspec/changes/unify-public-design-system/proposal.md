## Why

The public portfolio has accumulated repeated eyebrows, dense metadata, defensive authorship copy, and overlapping visual effects that make the strongest work harder to scan. This change establishes one quieter public interface system while preserving the portfolio's ASCII and printed-paper character.

## What Changes

- Define a shared public hierarchy, surface, type, spacing, responsive, and state contract for the public portfolio routes.
- Remove redundant contextual labels, generalized eyebrow props, and defensive AI-authorship disclaimers from the public reading experience.
- Make case, note, contact, CV, lab, and homepage compositions more readable while retaining their existing routes, renderer contracts, theme behavior, and scoped identities.
- Limit motion to purposeful continuity and explicit interaction feedback, with readable no-JavaScript and reduced-motion rest states.
- Document the design and verification plan in a spec-driven OpenSpec change.

## Capabilities

### New Capabilities

- `public-interface-system`: Shared public-page hierarchy, visual primitives, responsive composition, themes, and scoped identities.
- `editorial-authenticity`: Evidence-grounded public copy and removal of generic or defensive editorial framing.
- `interaction-quality`: Consistent public control, dialog, motion, and fallback behavior across pointer, keyboard, touch, reduced-motion, and no-JavaScript states.

### Modified Capabilities

- None.

## Impact

Affected public Astro routes, two shared case/project components, the shared CSS and motion runtime, public case-study and local note copy, browser coverage, and the Codex harness record. No dependency, renderer, route, contact-backend, or WebGL implementation change is required.
